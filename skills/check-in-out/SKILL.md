# Check-in / Check-out Operations

## Standard times

- Check-in: 15:00 — guest arrives, ID + folio, key card issued
- Check-out: 11:00 — folio closed, key returned, departure marked

## Early arrival (before 15:00)

If room is ready: check them in immediately, no charge.
If not ready:
1. Offer to store luggage at concierge (always free).
2. Offer the lounge / restaurant / spa.
3. Give a callable ETA — "we'll have your room within 60 minutes / by 13:30".
4. If guest is Platinum+: prioritise their room with HK Sup.

## Late check-out

| Request | Gold+ | Silver | None |
|---|---|---|---|
| Up to 13:00 | Free | Free | Free if low occupancy, else $20 |
| Up to 14:00 | Free | $30 | $30 |
| Up to 16:00 | Free if available | Half-day rate | Half-day rate |
| After 16:00 | Half-day rate | Half-day rate | Half-day rate |

Always check today's occupancy with the system before promising late checkout
after 14:00 on a high-occupancy day.

## Lost key card

- Verify identity (ID at desk, photo if remote / Telegram).
- Issue new key, deactivate the old one.
- Log incident in security if multiple lost cards in a stay.

## Room change

Common reasons:
- AC / plumbing / TV defect (route maintenance first; if not fixable in 15
  min, offer change)
- Noise (move to a higher / quieter floor)
- Wrong room type (sales error)

Procedure:
1. Confirm new room ready with HK.
2. Offer porter to move bags (free).
3. Walk the guest up if VIP or upset.
4. Adjust folio if rate changes.

## Common guest questions and answers

- "What time can I check in?" → "15:00 standard; we can hold your bags from
  any earlier time. I can prioritise your room — what time will you arrive?"
- "Can I get late check-out?" → quote from the table above with the guest's
  tier in mind.
- "Where do I drop my key?" → "At reception, anytime. Or just leave it in
  your room — we'll take care of it."

# Guest Feedback Sweep

Each day at 17:00, Concierge sweeps the day's guest feedback and posts a structured summary on `projects/guest-experience`.

## What to include

- **Reviews landed today** — Booking / Tripadvisor / Google / brand survey, with star / score and one-line gist. Draft response for negatives.
- **In-stay touches** — short notes from any guest interaction worth remembering (preferences, returning, special occasion).
- **Recovery cases open** — list each with status (action taken, awaiting confirmation, closed).
- **Themes** — what's recurring this week. If a theme crosses three days, flag the responsible HOD for root-cause work.
- **VIP arrivals tomorrow** — pre-arrival sheet status (drafted / posted / amenity placed).

## Handoffs

- **GM** signs off on review responses with named criticism.
- **DOR / D F&B / Chief Engineer** receive themed root-cause asks.
- **Housekeeping Sup** receives any same-day amenity / room-touch ask for tomorrow's VIPs.
